## YYYY-MM-DD - Global Focus and Screen Reader Accessibility
**Learning:** Found that custom interactive components (like the Command Center, Sidebar Tabs, and Activity Bar) were built with standard `<div>` elements without accessibility attributes. This meant they were completely invisible to keyboard users and screen readers. Additionally, there was no consistent visual focus state for inputs and buttons across the IDE.
**Action:** Applied `role="button"`, `role="tab"`, `aria-label`, and `tabindex="0"` to all custom interactive elements and icon-only buttons. Added a global `:focus-visible` rule in CSS (`outline: 2px solid var(--primary); outline-offset: -2px;`) to provide a modern, highly visible focus ring that only appears for keyboard users, avoiding visual noise for mouse users. Next time, remember that while adding `tabindex="0"` makes `div`s focusable, their associated JS handlers also need to listen for `keydown` (Enter/Space) to fully replicate native button behavior.
